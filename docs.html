Introduction

Animaticons is a collection of 1,026 animated SVG icons in two packs: Aura (crisp outlines) and Ember (soft tinted fills). Every icon ships with its motion baked in — a short, purposeful animation that plays when you hover, click, or tell it to.

  • Two packs, 513 designs each, across 33 tidy categories.
  • Every icon accepts the same options: size, color, duration and isAnimated.
  • Imperative control with startAnimation() and stopAnimation().
  • Respects the user's Reduce Motion setting out of the box.
  • MIT licensed — use it in personal and commercial work, no attribution required.
New here? Browse the gallery, hover a few icons, and copy the snippet you like — the docs can wait.

Installation

Pick the package that matches your stack. Motion is bundled — there is nothing else to install.

React

terminal
npm i @animaticons/react
# or
pnpm add @animaticons/react

Vue

terminal
npm i @animaticons/vue

Plain HTML / everyone else

terminal
npm i @animaticons/vanilla

Just one icon?

Skip the package entirely: open any icon page, tweak it until it's perfect, then hit Copy or Download SVG. The code is yours — paste it into any component and edit the paths freely.

Basic usage

Icons are named after their gallery id in PascalCase with Icon at the end. The pack is chosen by the import path.

react
import { BellRingIcon } from "@animaticons/react/aura";

export function Notifications() {
  return <BellRingIcon size={28} />;
}

Prefer the warm tinted pack? Swap the subpath:

react
import { BellRingIcon } from "@animaticons/react/ember";

Plain HTML works with a tiny helper and a mount point:

html
<div id="slot"></div>
<script type="module">
  import { createIcon } from "@animaticons/vanilla";
  import { BellRing } from "@animaticons/vanilla/aura";

  const el = createIcon(BellRing, { size: 32, color: "tomato" });
  document.querySelector("#slot").append(el);
</script>

Props

The same options work in React, Vue and the vanilla helper.

PropTypeDefaultWhat it does
sizenumber24Width and height in pixels.
colorstringcurrentColorStroke (and tint) color. Falls back to the text color.
durationnumber1Speed multiplier. 0.5 plays twice as fast, 2 at half speed.
isAnimatedbooleantruePlay on hover. Set false to drive it only from code.
classNamestring–Extra classes for styling the wrapper.

Animation triggers

Out of the box every icon plays when the pointer enters and resets when it leaves. For anything fancier, grab a ref and call the imperative methods:

react
import { useRef } from "react";
import { HeartIcon } from "@animaticons/react/aura";

export function LikeButton() {
  const ref = useRef(null);

  return (
    <button
      onClick={() => ref.current?.startAnimation()}
      onMouseLeave={() => ref.current?.stopAnimation()}
    >
      <HeartIcon ref={ref} size={22} isAnimated={false} />
      Like
    </button>
  );
}
  • startAnimation() — play from the beginning.
  • stopAnimation() — pause and snap back to rest.
  • Both methods work in the vanilla helper too: el.startAnimation().

Customize

Every animation is driven by CSS variables and keyframes, so you can restyle motion like any other CSS. Speed and color are the most common knobs:

react
<SparklesIcon
  size={48}
  color="#F2892C"
  duration={0.6}
  className="hero-sparkle"
/>

And in plain CSS, once the icon is on the page:

css
.hero-sparkle {
  color: #F2892C;        /* stroke + tint */
  --dur: 0.8;            /* faster motion */
}

.hero-sparkle:hover [data-a="pop"] {
  animation-timing-function: cubic-bezier(0.2, 1.4, 0.3, 1);
}
Ember tip. The tinted fills follow the same color, so one variable themes the whole icon — line and fill together.

Accessibility

  • Animations are decorative by default — icons are aria-hidden unless you pass a label.
  • Reduce Motion: when a user asks for less motion, Animaticons's animations stop. The icons stay fully usable.
  • Icon-only buttons should always carry an aria-label (see the gallery buttons for a pattern).
  • Keep an eye on contrast: currentColor inherits your text color, which is usually already AA-compliant.
